The colours are vermilion `#D5412E`, ink `#25251F` and warm paper `#F5F0E6`. The dark logo uses vermilion `#F07860` with paper-coloured lettering.

Leave one eighth of the symbol's width clear around it. Below a logo width of 240 pixels, use the symbol alone. Keep the symbol at least 24 pixels wide.

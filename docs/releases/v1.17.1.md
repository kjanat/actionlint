actionlint 1.17.1 updates the Go toolchain and container packages to address the vulnerabilities reported in #356. It also fixes validation of actions at the repository root. This is a small maintenance release for v1; configuration and check defaults are unchanged.

## Upgrade to patched binaries and images

The release binaries, Docker images, and Nix package now build with Go 1.27.3, including its standard-library security fixes. Docker images also update their installed Alpine packages.

The release workflow now checks Go packages with govulncheck and scans the Docker smoke-test images with OSV Scanner before publication. Thanks @konard for reporting the vulnerable packages in the 1.17.0 image. Related: #356.

## Call an action at the repository root

A step using `uses: $/` now resolves to the repository's root action instead of producing an invalid-format error. For a repository with an `action.yml` or `action.yaml` at its root:

```yaml
steps:
  - uses: $/
    with:
      message: hello
```

actionlint reads that action's metadata and validates its inputs and outputs. Unknown input names and references to undeclared outputs still produce diagnostics. Thanks @mattdowdell for reporting the problem and identifying its cause in #199. Fixed in #200.

## Upgrade

```sh
npm install --save-dev @kjanat/actionlint@1.17.1
```

For a one-off run:

```sh
npx @kjanat/actionlint@1.17.1 -version
```

For Docker:

```sh
docker pull ghcr.io/kjanat/actionlint:1.17.1
```

For the GitHub Action:

```yaml
- uses: kjanat/actionlint@v1.17.1
```

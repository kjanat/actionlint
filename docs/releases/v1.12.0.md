v1.12.0 gives the fork its permanent Go module address, refreshes the browser Playground, and fixes missing checks in container volume expressions. It also improves cancellation for library users and verifies downloaded binaries when GitHub's attestation tooling is available.

## Move Go installations and imports to the vanity module

The module is now `actionlint.kjanat.dev`:

```sh
go install actionlint.kjanat.dev/cmd/actionlint@v1.12.0
```

Library consumers should update imports from `github.com/kjanat/actionlint` to:

```go
import "actionlint.kjanat.dev"
```

The module address resolves to this repository through the site's Go discovery metadata. The executable name stays `actionlint`.

There is also a Go API rename: `InvalidGlobPattern` becomes `InvalidGlobPatternError`, the error type returned by `ValidateRefGlob` and `ValidatePathGlob`. Code referring to that exported type needs the new name.

## Find and understand errors in the Playground

The Playground now uses Vite, CodeMirror 6, and the editor's lint integration. Findings appear as inline underlines and tooltips, making it easier to connect an error to the text being edited. The WebAssembly bridge passes the end column of a diagnostic so the editor can highlight its range.

Diagnostic end columns are also corrected for wide and non-ASCII characters. This affects GitHub annotations and custom `-format` output using `EndColumn`, keeping the end position aligned with the source instead of the visual width of the printed underline.

## Check expressions in container volumes

Container `volumes` were accidentally stored in the `ports` field. When both keys were present, the later list overwrote the earlier one, which could drop expressions from validation.

For example, the misspelled context property in this workflow is now checked:

```yaml
on: push
jobs:
  build:
    runs-on: ubuntu-latest
    container:
      image: ubuntu:24.04
      volumes:
        - ${{ github.workspce }}:/workspace
      ports: [8080]
    steps:
      - run: echo ready
```

Correct it to `github.workspace`. The parser now keeps `ports` and `volumes` separately, and checks expressions in the volume strings.

## Cancel embedded lint runs cleanly

`LinterOptions` gains a `Context` field. Applications embedding actionlint can provide a cancellable context or a deadline, and cancellation now reaches the ShellCheck and pyflakes subprocesses as well as process scheduling. This is useful for editor integrations, servers, or jobs that must stop obsolete lint work.

Type assertions in `UpdateInputs` and `UpdateDispatchInputs` are checked too, preventing a panic if an unexpected expression-variable type reaches those paths.

## More ways to install and verify the binary

The CLI image is now published to Docker Hub as `kjanat/actionlint` as well as `ghcr.io/kjanat/actionlint`, with the same manifest in both registries. The separate `action-*` images remain on GHCR.

The download script verifies the archive's build provenance when `gh` is installed and authenticated, and prints a notice when verification is skipped. Binary attestations are available from v1.11.0 onward.

Homebrew publication to `kjanat/homebrew-actionlint` is enabled in this release. That tap was later migrated to `kjanat/homebrew-tap` in v1.15.0; use the [current installation guide](https://github.com/kjanat/actionlint/blob/master/docs/install.md) for today's tap name.

## Contributor improvements

The manual is generated from Markdown with Pandoc, removing the Ruby/ronn setup. Native Go fuzz targets now participate in compilation, vetting, and tests, and `make fuzz` runs them. The build no longer risks overwriting expected-output fixtures through Make's implicit rules.

Code generators have HTTP deadlines and confined output paths, and availability generation produces stable output across repeated runs. Repository linting now includes golangci-lint and optional ShellCheck rules for its own workflows. Workflow permissions are explicit, action references are pinned, dprint replaces Prettier and Stylelint, and timestamp files and the pre-push hook are removed from the build.

Upgrade for the volume-expression fix and better diagnostic ranges; Go library users should also account for the module and exported-error renames. The main modernization work is in kjanat/actionlint#22.

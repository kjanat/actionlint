# Security policy

## Supported versions

| Version                        | Supported |
| ------------------------------ | --------- |
| [Latest minor release][latest] | Yes       |
| Older releases                 | No        |

Report vulnerabilities in 1.7.x and earlier to [rhysd/actionlint].

## Reporting a vulnerability

Report a vulnerability through [private vulnerability reporting][report] or by [email](mailto:security+actionlint@kajkowalski.nl). Include the affected version, the installation method and a workflow, configuration or command line that reproduces the problem.

I acknowledge reports within 7 days. I publish each fix in a new release with a GitHub security advisory and credit the reporter.

Report an insecure workflow pattern that actionlint misses as a regular [issue].

[issue]: https://github.com/kjanat/actionlint/issues/new
[latest]: https://github.com/kjanat/actionlint/releases/latest
[report]: https://github.com/kjanat/actionlint/security/advisories/new
[rhysd/actionlint]: https://github.com/rhysd/actionlint/security
